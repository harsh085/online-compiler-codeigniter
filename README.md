# 💻 CodeRank: A Centralized Coding Platform for Students and Faculty

**CodeRank** is a powerful web-based coding platform designed for **colleges**, **programming clubs**, and **boot camps**. Hosted on a local intranet, it allows users to **compile and run code across multiple languages**—all without needing any compilers or setup on individual systems. It’s your fully customizable, self-hosted alternative to third-party online compilers.

---

## 🚀 Key Features

- 🌐 **Web-based Compiler**: No installations required on individual machines.
- 🖥️ **Multi-language Support**: Execute code in various programming languages (C, C++, Python, Java, etc.).
- 🔐 **Intranet Deployment**: Fast and secure, runs entirely within the campus network.
- 🧩 **Modular Architecture**: Seamless integration of login, code editor, and file manager.
- 🧠 **Customizable Backend**: Add languages, testing conditions, and problem sets specific to your institution.

---

## 🔧 Why CodeRank?

While mainstream online compilers (e.g., OnlineGDB) offer accessibility, they come with restrictions like:
- Limited backend control
- Data dependency on third parties
- Lack of flexibility for curriculum-specific needs

**CodeRank** is **completely self-hosted** and **owned** by your institution. This means:
- Full backend access  
- Ability to add custom problem sets and exam conditions  
- Secure and adaptable for future needs  

Whether it's for coding events, competitive programming, or semester exams — **CodeRank scales with you**.

---

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: Python, Flask (or Node.js, based on deployment)  
- **Compiler Integration**: Docker, APIs for language execution  
- **Deployment**: Hosted on campus intranet servers

## ⚙️ How It Works

1. Users log in through the secure portal.
2. Code is written in a built-in editor.
3. Code is sent to the server for execution.
4. Output is returned in real-time—no local compilers required.
